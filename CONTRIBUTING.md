# Contributing

Nara Firmware is a personal, source-available project. It is not maintained as
a community open-source project.

Unsolicited pull requests are not accepted by default. Please do not submit
source code, board ports, assets, documentation, or other copyrightable
material unless the repository owner has explicitly invited the contribution.

Before any third-party contribution is merged, the repository owner may
require a separate written copyright assignment, contributor agreement, or
other license grant. A GitHub submission alone must not be interpreted as
transferring ownership of Nara Firmware or granting permission to use
Nara-owned material outside the terms in LICENSE.

Bug reports and technical discussion may be useful, but they do not grant any
license to Nara-owned code.

Third-party material must preserve its original copyright and license notices.
See LICENSE and THIRD_PARTY_NOTICES.md.
